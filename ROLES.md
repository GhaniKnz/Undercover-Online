# Rôles du jeu Undercover

Cette liste regroupe les rôles disponibles dans la version en ligne du jeu **Undercover**. Elle comprend les rôles de base ainsi que plusieurs rôles optionnels pour enrichir les parties.

## 🌟 Rôles de base

1. **Citoyen**
   - **But** : Trouver les Undercover et Mister White.
   - **Mot donné** : Mot commun partagé avec les autres citoyens.
   - **Actions** :
     - Donne un indice sans dévoiler le mot.
     - Vote pour éliminer les suspects.
   - **Perd** : Si tous les citoyens sont éliminés ou s'ils éliminent un citoyen par erreur.

2. **Undercover**
   - **But** : Tromper les Citoyens et Mister White.
   - **Mot donné** : Mot similaire mais différent de celui des Citoyens.
   - **Actions** :
     - Fait croire qu'il est Citoyen.
     - Donne un indice qui ne trahit pas son mot.
     - Vote contre les Citoyens et Mister White.
   - **Gagne** : S'il reste le dernier ou si tous les Citoyens sont éliminés.

3. **Mister White**
   - **But** : Deviner le mot des Citoyens.
   - **Mot donné** : Aucun.
   - **Actions** :
     - Invente un indice crédible.
     - Peut tenter de deviner le mot à tout moment.
   - **Gagne** :
     - En devinant le mot correctement.
     - Ou s'il est éliminé en dernier.

## 🛡️ Rôles optionnels

4. **Détective**
   - **But** : Aider les Citoyens à identifier les Undercover.
   - **Mot donné** : Identique aux Citoyens.
   - **Pouvoir** : Peut une fois par partie découvrir secrètement le rôle d'un joueur.
   - **Gagne** : Avec les Citoyens.

5. **Espion**
   - **But** : Soutenir les Undercover.
   - **Mot donné** : Identique aux Undercover.
   - **Pouvoir** : Peut échanger un message secret avec un autre Undercover une fois par partie.
   - **Gagne** : Avec les Undercover.

6. **Le Muet**
   - **But** : Citoyen particulier incapable de parler.
   - **Mot donné** : Identique aux Citoyens.
   - **Pouvoir** : Doit communiquer son indice par geste ou émoticône.
   - **Gagne** : Avec les Citoyens.

7. **Le Caméléon**
   - **But** : Joueur neutre.
   - **Mot donné** : Reçoit aléatoirement le mot des Citoyens ou des Undercover.
   - **Pouvoir** : Peut choisir de rejoindre ou de trahir son camp initial selon la situation.
   - **Gagne** : Avec le groupe correspondant à son mot de départ.

8. **Le Saboteur**
   - **But** : Faire durer la partie le plus longtemps possible sans favoriser un camp précis.
   - **Mot donné** : Optionnel ou incohérent.
   - **Pouvoir** : Sème la confusion par des indices flous.
   - **Gagne** : Si la partie atteint un certain nombre de manches sans qu'il soit éliminé.

9. **Le Voleur**
   - **But** : Opportuniste qui adopte le rôle d'un joueur éliminé.
   - **Mot donné** : Aucun au départ.
   - **Pouvoir** : Au premier tour, peut voler le rôle (et le mot) d'un joueur éliminé.
   - **Gagne** : Avec le camp dont il a volé le rôle.
